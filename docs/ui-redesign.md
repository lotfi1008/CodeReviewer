# بازطراحی پنل — ۲۰ سپتامبر ۲۰۲۶

اصل طراحی: هر صفحه یک هدف اصلی دارد. فهرست و گزارش، ویرایش و فهرست، و لاگ و گزارش مسیرهای جداگانه دارند.

| صفحه | مسیر | هدف |
|---|---|---|
| خانه | `/` | انتخاب مسیر شروع |
| درخواست‌ها | `/requests` | جست‌وجو و انتخاب MR/PR |
| تغییرات | `/request/changes` | خواندن Diff یک درخواست |
| شروع بازبینی | `/request/review` | انتخاب پروفایل و مدل، اجرا و توقف |
| یادداشت‌ها | `/request/notes` | خواندن یادداشت‌ها و پاسخ‌های ذخیره‌شده |
| نوشتن یادداشت | `/request/note` | ثبت یادداشت روی نسخه یا خط کد |
| کمک AI | `/request/help` | پرسش دربارهٔ یک فایل |
| جمع‌بندی انسانی | `/request/decision` | ثبت نظر نهایی بازبین |
| سوابق | `/history` | فهرست با صفحه‌بندی SQL در دسته‌های ۱۵تایی |
| گزارش | `/reviews/{id}` | نتیجه، شواهد و پوشش فایل‌ها |
| لاگ | `/reviews/{id}/log` | رویدادهای اجرا |
| انتشار | `/reviews/{id}/publish` | پیش‌نمایش کامنت و همگام‌سازی آن |
| اتصال‌ها | `/settings` | انتخاب نوع اتصال |
| سورس کنترل | `/settings/sources` | فهرست اتصال‌ها |
| مدل‌ها | `/settings/models` | فهرست مدل‌ها |
| ویرایش اتصال | `/settings/{kind}/{id-or-new}` | تنظیم یک اتصال |
| پروفایل‌ها | `/profiles` | انتخاب روش بازبینی |
| ویرایش پروفایل | `/profiles/{id-or-new}` | تنظیم روش، پرامپت و محدودیت‌ها |

صفحه‌های درخواست از پارامترهای source، repo و number استفاده می‌کنند. file و line زمینهٔ انتخاب‌شده را میان صفحه‌های یادداشت و تغییرات منتقل می‌کنند. لینک قدیمی `/requests?...` به صفحهٔ تغییرات و `/history?run=...` به گزارش مستقل هدایت می‌شود.

ظاهر: منوی سفید، زمینهٔ روشن، سبز تیره برای اقدام اصلی، وزیرمتن محلی و RTL. کد و مسیر فایل LTR هستند. فرم پروفایل تنظیمات پیشرفته را جمع می‌کند. چیدمان زیر ۷۶۰ پیکسل تک‌ستونی است.

## گزارش کاربردی

در هر فراخوانی Review، مدل توضیح تغییر، تحلیل مبتنی بر شناسه‌ها/خطوط و یک بررسی انسانی پیشنهادی برمی‌گرداند. این توضیح‌ها همراه شمار خطوط، فایل‌های خارج از محدوده، کوتاه‌شدن Diff و تعداد پیشنهادهای پذیرفته/ردشده در SQL ذخیره می‌شوند. این متن تحلیل مدل است و جایگزین اجرای تست نیست.

کامنت از نتیجه و اقدام شروع می‌شود؛ مدل، پروفایل و SHA در بخش جمع‌شونده قرار دارند. اجرای بدون یافته و بدون توضیح مستند منتشر نمی‌شود. توضیح برای اجرای قدیمی ساخته نمی‌شود. در آزمون واقعی، اجرای `48cd5577-22dd-4089-8e18-ec31bd686e4c` یک فایل را در حدود ۳۱ ثانیه تحلیل کرد و کامنت شمارهٔ ۱۸ را روی MR شمارهٔ ۴ به‌روزرسانی کرد؛ ۳۷ فایل دیگر بررسی نشده/خارج از محدوده بودند.
