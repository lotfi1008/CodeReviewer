# ارزیابی نسخهٔ عملیاتی — ۲۰ سپتامبر ۲۰۲۶

## تغییرات تأییدشده

- سقف آزمایشی فایل و فیلتر C# حذف شد؛ تمام Diffهای متنی ورودی پردازش می‌شوند. Diff بزرگ بدون حذف انتهای متن به بخش‌ها تقسیم می‌شود.
- انتخاب چند حوزه در یک پروفایل، مدل و دستور هر حوزه، قواعد اجباری بیزینس و ذخیرهٔ snapshot پروفایل در SQL پیاده شد. فرم در مرورگر بررسی شد؛ انتخاب بیزینس، کادر قواعد و تنظیم مدل اختصاصی را نمایش می‌دهد.
- صف SQL از مرورگر مستقل است؛ بازیابی کار، لغو و جلوگیری از درج مجدد یافته‌ها در اجرای بازیابی‌شده آزمون شد.
- لاگ امن شامل کد HTTP و توضیح خطاست. خطاهای موقت حداکثر سه تلاش در مهلت اصلی دارند. خطای احراز هویت تکرار نمی‌شود و متن خام سرویس وارد لاگ نمی‌شود.
- ۳۹ آزمون خودکار موفق، بدون شکست یا skip. شامل SQL واقعی محلی، شکست مدل، deadline، chunk کامل، پروفایل بیزینس، انتشار بدون تکرار و کنترل SHA با سرویس شبیه‌سازی‌شده.
- بستهٔ Release IIS ساخته شد. اجرای بسته در Production با دیتابیس موقت مستقل موفق بود و درخواست ناشناس HTTP 401 دریافت کرد. ورود Windows در آزمایش Kestrel محلی HTTP 400 گرفت؛ تأیید ورود و مجوز گروه روی IIS مقصد هنوز لازم است. دیتابیس موقت پس از آزمون حذف شد.

## اجرای واقعی

MR شمارهٔ ۴ پروژهٔ ۲۳ GitLab، SHA برابر `0b36edf24cccb0e1ef0ada4d112d61c05210eb05`.
شناسهٔ اجرا: `7b9f3ff1-0d71-4351-a9b0-265ff6af817e`.
۳۸ فایل شامل C#، Markdown و Razor؛ حوزه‌های صحت عملکرد و امنیت؛ مدل ذخیره‌شدهٔ `aifa / developer-model`.

در اجرای واقعی، `HostingExtentions.cs` از مهلت ۱۲۰ ثانیه عبور کرد. بعضی پاسخ‌های سرویس مصرف خروجی بیشتر از سقف درخواستی گزارش کردند. این مشاهده ناسازگاری احتمالی شمارش یا اعمال سقف توکن را نشان می‌دهد و به‌تنهایی علت داخلی مدل را اثبات نمی‌کند. نتیجهٔ نهایی و جزئیات هر فایل در SQL و صفحهٔ گزارش همین شناسه ثبت می‌شود.

## موارد لازم پیش از پذیرش انتشار

- رفع/تنظیم زمان پاسخ سرویس مدل و تکمیل پوشش MR بدون timeout.
- مشخص‌شدن مقصد IIS و گروه مجاز، انتقال صحیح secrets، تأیید Windows Authentication و آزمون راه‌اندازی مجدد روی همان مقصد.
- ثبت قواعد واقعی برای حوزهٔ بیزینس؛ هنوز هیچ قاعدهٔ فرضی به نام کاربر ثبت نشده است.
- پایلوت ۲۰ MR و داوری انسانی اعتبار یافته‌ها هنوز انجام نشده است؛ آزمون‌های خودکار جای این معیار را نمی‌گیرند.

بستهٔ قابل نصب، معادل انتشار روی سرور سازمان یا تأیید نهایی عملیاتی نیست. جزئیات استقرار در [deployment.md](deployment.md) است.
