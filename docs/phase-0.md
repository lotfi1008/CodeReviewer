# فاز ۰: آماده‌سازی و اعتبارسنجی اتصال‌ها

## وضعیت فعلی

| معیار | وضعیت در ۱۸ سپتامبر ۲۰۲۶ |
|---|---|
| .NET 10 SDK | آماده؛ نسخه 10.0.400 |
| اتصال شبکه به GitLab | برقرار؛ صفحه ورود پاسخ HTTP 200 داد |
| اعتبار گواهی HTTPS GitLab | ناموفق؛ ریشه گواهی در این دستگاه مورد اعتماد نیست |
| نسخه GitLab | نامشخص؛ endpoint نسخه بدون احراز هویت HTTP 401 داد |
| MR آزمایشی و دسترسی Diff | انتخاب MR از فهرست پروژه‌ها پس از ثبت توکن API در UI |
| endpoint مدل داخلی | هنوز ارائه نشده است |
| سازگاری پاسخ ساختاریافته مدل | منتظر endpoint و کلید مدل |

نشانی شناخته‌شده GitLab: `https://5.160.84.190:60443`.

## پیش‌نیازهای باقی‌مانده

1. گواهی صادرکننده GitLab را در trust store دستگاه توسعه و سرور عملیاتی نصب کنید، یا نام DNS معتبر همراه با گواهی مورد اعتماد ارائه کنید. آزمون عملیاتی نباید با غیرفعال کردن اعتبارسنجی TLS انجام شود.
2. یک توکن API با دسترسی خواندن MR، Diff و فایل‌های مخزن در صفحه Connections سامانه ثبت کنید. سامانه پروژه‌ها و MRهای باز را خودش فهرست می‌کند؛ وارد کردن لینک MR لازم نیست. نشست Edge، جای توکن سرویس را نمی‌گیرد. مجوز نوشتن Discussion در فاز ۴ لازم خواهد شد.
3. نشانی HTTPS endpoint مدل داخلی، نام مدل و کلید دسترسی آن را فراهم کنید. ابزار فعلی endpoint سازگار با OpenAI Chat Completions و JSON Schema را آزمایش می‌کند. اگر endpoint پروتکل دیگری دارد، adapter آزمون پیش از تأیید این فاز باید مطابق همان پروتکل ساخته شود.

## اجرای ابزار اعتبارسنجی

متغیرها را فقط در نشست فعلی PowerShell تنظیم کنید؛ مقدار Secret را در فایل پروژه یا تاریخچه فرمان ذخیره نکنید. پس از تنظیم متغیرها، از ریشه پروژه اجرا کنید:

```powershell
dotnet run --project tools/CodeReviewer.Phase0Probe -- gitlab
dotnet run --project tools/CodeReviewer.Phase0Probe -- model
```

متغیرهای GitLab:

| نام | مقدار |
|---|---|
| `REVIEW_GITLAB_URL` | نشانی پایه HTTPS، ترجیحاً با نام DNS معتبر |
| `REVIEW_GITLAB_TOKEN` | توکن API |
| `REVIEW_GITLAB_PROJECT` | شناسه عددی پروژه یا مسیر URL-encoded آن |
| `REVIEW_GITLAB_MR_IID` | شماره MR داخل پروژه |

متغیرهای مدل:

| نام | مقدار |
|---|---|
| `REVIEW_MODEL_ENDPOINT` | نشانی پایه HTTPS سازگار با OpenAI |
| `REVIEW_MODEL_API_KEY` | کلید دسترسی |
| `REVIEW_MODEL_NAME` | شناسه مدل |

برای ورود تعاملی Secret به نشست PowerShell می‌توان از `Read-Host -AsSecureString` استفاده کرد. ابزار فقط وضعیت آزمون، نسخه GitLab و Head SHA نمونه را چاپ می‌کند و خود توکن‌ها را چاپ نمی‌کند.

## معیار عبور از فاز ۰

- نسخه GitLab با احراز هویت خوانده شود.
- MR آزمایشی و دست‌کم اولین صفحه Diff آن قابل دریافت باشد.
- مدل داخلی از مسیر `IChatClient` یک Finding ساختاریافته معتبر با JSON Schema برگرداند.
- اتصال‌ها با اعتبارسنجی عادی TLS برقرار شوند.

تا تحقق این چهار مورد، فاز ۱ آغاز نمی‌شود.
